## Mission: Cells with names

**What you will see**: the table looks exactly as before.

Every cell of a flight row should say what it holds, so CSS and JavaScript can find it.

- In every row of the table's body, the first cell has the class `code`. Later lessons use these names.
- The second cell has the class `destination`.
- The third cell has the class `departs`.
- The fourth cell has the class `status`.
- The five flights stay in the same order.
