No new theory, just a challenge that uses the HTML of this part: labels, names, input types, length limits, and a question over a group.

Every passenger leaves someone on Earth: a parent, a friend. If something goes wrong on a flight, the station needs to call them. And soon, styles and a script will work on this form, so they need a way to find it.

## Mission: Someone to call

**What you will see**: before the notes, a new frame with a question like "Someone we can call on Earth". In it, there is a box for their name and one for their phone number, each with its label. Fill in the whole form and send: the console's line has `contact-name=Lena Park&contact-phone=+44 20 7946 0000` in it.

Your booking form asks about the passenger, the flight, the seat and the extras, but not about anyone back home.

- The form has the id `booking`. Later lessons use it.
- A group with a question over it holds the contact's name: the id and the name are `contact-name`.
- The same group holds the contact's phone number: the id and the name are `contact-phone`.
- Each box has a label that takes you to it.
- On a phone, the contact's phone box shows the keyboard for calling.
- The contact's name takes at most 40 characters.
- Both are optional: a booking without them is sent.
- A whole booking, with every box filled in, sends them all.
